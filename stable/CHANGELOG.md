# Nocturne Stable — HA package 0.2.43401

Nocturne version/source: `0.3.0`.

This is the required Nocturne 0.3.0 database migration bridge. Install and start this package successfully before installing a 0.3.1 or newer package. The existing add-on identity and private data directory are retained.

Published architectures: amd64, aarch64. Both use the same Nocturne source.
